Fyrvokteren

Tåka ruller inn, og havet sender opp sine krypdyr. Hold lyset i fyret brennende gjennom ti bølger.

  • Gå: WASD / piltaster, klikk på bakken, joystick eller venstre stikke · Zoom: scroll / klyp / LT-RT · Kamera: høyreklikk-dra / høyre stikke
  • Bygg tårn på de gamle steinsoklene: still deg ved en sokkel og trykk 1 / 2 / 3, eller velg med Q/R (LB/RB) og trykk B (Ⓐ / ✕ / A)
  • Monstre etterlater glør som slukner etter noen sekunder. Løp og hent dem!
  • Bær (E / mellomrom / Ⓑ / ○ / B): hent en fyrstein i fyret (30 ✦) og bær den til et tårn for å oppgradere (maks nivå 3)
  • Pause: Esc / Start · Alle kontroller virker samtidig, også Xbox-, PlayStation- og Switch-kontroller.
  • Hvert monster som når fyret slukker én av 20 flammer. Måker kan slå deg i bakken.
