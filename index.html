Glødevokteren

På toppen av det gamle fyret ulmer øyas stolthet, en kjempe-joint som har glødd i hundre år. Nå marsjerer Forbudsdirektoratet i land med stempler, talerstoler og komitéer for å slukke den. Du er vokteren: chill dem ned, sank glørne de mister, og hold gløden i live gjennom ti bølger.

  • Gå: WASD / piltaster, klikk på bakken, joystick eller venstre stikke · Zoom: scroll / klyp / LT-RT · Kamera: høyreklikk-dra / høyre stikke
  • Bygg tårn på steinsoklene: still deg ved en sokkel og trykk 1 / 2 / 3, eller velg med Z/X (LB/RB) og trykk B (Ⓐ / ✕ / A)
  • Chillede fiender mister glør som slukner etter noen sekunder. Løp og hent dem!
  • Bær (E / mellomrom / Ⓑ / ○ / B): hent rullepapir ved fyret (30 ✦) og bær det til et tårn for å oppgradere (maks nivå 3)
  • Hver fiende som når fyret slukker litt av gløden (20 punkter). Moralpanikk-måker kan slå deg ut.
  • Pause: Esc / Start · Start kartet på nytt: R / Select (View, −) · Grafikk Høy/Lav: G eller knappen oppe til høyre · Alle kontroller virker samtidig.
